# Las aventuras de Paco

Juego de plataformas para Android (hecho con Flutter). Paco, un gato, recorre
10 mundos de 8 niveles cada uno hasta vencer al Perro Supremo.

| Mundo | Tema | Niveles 4 y 8 |
|---|---|---|
| 1 | Planicies, cielo y bosque | Castillos |
| 2 | Desierto | Pirámides |
| 3 | Playa (niveles 5 a 8 bajo el agua) | Barco y submarino |
| 4 | Cielo | Castillos en el cielo |
| 5 | Nieve | Iglús |
| 6 | Ciudad del futuro | Fábrica de robots |
| 7 | Lava (volcanes en los niveles 3 y 6) | Fortaleza de lava |
| 8 | Océano envenenado | Laboratorio tóxico |
| 9 | Prueba de todas las habilidades | Torre de prueba |
| 10 | Bosque abandonado | Castillo del Perro Supremo (solo el nivel 8) |

## Cómo se juega

- Flechas para moverse y el botón naranja para saltar (bajo el agua, para nadar).
- Salta encima de los perros para vencerlos. Las bolas de fuego no se pueden pisar.
- Recoge pescados. Los corazones dan una vida extra.
- La bandera de la mitad del nivel guarda tu avance.
- En los niveles 4 y 8 hay un perro jefe: písalo varias veces.

En el ordenador: flechas o A/D para moverse, espacio o W para saltar, P para pausa.

## Descargar

- **APK para Android:** pestaña *Actions* → último "Compilar APK" → *Artifacts*.
- **Versión web (iPhone):** https://alemarcheco.github.io/juego-plataformas/
